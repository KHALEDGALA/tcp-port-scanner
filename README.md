
# TCP Port Scanner

A Python-based TCP port scanner built for learning
networking and socket programming.

## Features

- TCP connection testing using Python sockets
- Concurrent scanning with ThreadPoolExecutor
- User-defined target and port range
- Input validation and basic error handling
- Scan summaries and timestamped logs
- Results saved to a text file

## Requirements

- Python 3.10 or newer
- No third-party packages required

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run:

   python main.py

4. Enter a target and a valid port range.

## Technologies

- Python
- Socket Programming
- TCP/IP
- Multithreading
- Exception Handling
- File Handling

## Responsible Use

Only scan systems you own or have
explicit permission to test.
